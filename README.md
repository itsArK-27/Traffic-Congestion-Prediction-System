# Traffic Congestion Prediction System

## Live Deployment
🌍 **[https://traffic-prediction-system-lyart.vercel.app/](https://traffic-prediction-system-lyart.vercel.app/)**

## Overview
The Traffic Congestion Prediction System is a web application designed to analyze and predict traffic patterns using machine learning. It features a React frontend and an Express/Python backend.

## Project Structure
- `.` (root) - React frontend application
- `backend/` - Node.js Express server with Python ML integration

For more details on setting up and running the project locally, please refer to the specific directories.
